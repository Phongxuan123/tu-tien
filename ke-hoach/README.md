# Thư mục kế hoạch từng tính năng

Quy ước làm việc: **mỗi lần bắt đầu thêm hoặc sửa một tính năng, tạo một file riêng trong thư mục này** (sao từ `_mau.md`) và viết kế hoạch + các chặng làm trước khi code. Trong lúc làm thì cập nhật checklist và nhật ký ngay trong file đó. Khi xong, `KE-HOACH.md` ở gốc chỉ ghi một mục ngắn (mục tiêu, kết quả, liên kết tới file ở đây). `KE-HOACH.md` vì vậy là nhật ký tổng; chi tiết để sửa lại sau này nằm ở đây.

Trang tổng ở gốc dự án: [KE-HOACH.md](../KE-HOACH.md) (bảng tiến độ có tích, danh sách để kiểm lại). Nhật ký cũ nguyên văn: [_nhat-ky-goc.md](_nhat-ky-goc.md).
